# 熬过去 - 人生模拟器

一款精心设计的 Web 人生模拟游戏，核心机制是**很难死掉**——每次绝境大概率会迎来转机，熬过去就会好。

## 🌟 特性

- **4 种出身**: 小镇青年、城市中产、富二代、农村出身，不同起点不同体验
- **4 种天赋**: 学习天赋、社交达人、财运亨通、健康体质
- **3 种性格**: 稳健型、冒险型、佛系型，影响事件概率和数值衰减
- **3 种难度**: 普通模式（转机率 90%）、硬核模式（70%）、休闲模式（100%）
- **沉浸式叙事引擎**: 44 张事件卡片 + 37 个日常小事，含分支选择、连锁事件、故事旗标追踪
- **人物关系系统**: 核心人物有名有姓有性格，关系值影响后续事件走向
- **个性化结局**: 根据你一生的选择生成独一无二的人生总结
- **转机系统**: 绝境时高概率触发转机，连续绝境触发「人生逆袭」超级事件
- **关键年龄选择**: 18 岁高考、22 岁考研、25 岁职业抉择……每个选择改变人生轨迹
- **成就系统**: 10 种成就等你解锁
- **快捷操作**: 医院、心理医生、彩票、相亲、买房、养宠物、旅行、股票、求职

## 🚀 快速开始

### 完整版（后端 API + 前端）

```bash
pip install flask flask-cors
python server.py
```

浏览器打开 http://localhost:5000

### 纯前端版（只读模式，不可操作）

```bash
cd web
python -m http.server 8080
```

浏览器打开 http://localhost:8080

## 🎮 游戏玩法

1. **创建角色**: 输入名字，选择出身、天赋、性格和难度
2. **度过每年**: 点击「下一年」推进时间，每年可能触发事件卡让你做出选择
3. **做出选择**: 每个选择会影响数值、人际关系和后续剧情走向
4. **管理状态**: 使用快捷操作恢复健康、快乐或尝试改变命运
5. **达成成就**: 活得更久、更有钱、更快乐！

### 核心机制

- **健康归零**: 90% 概率触发转机（绝境逢生），10% 概率去世
- **绝境转机**: 健康 < 20、金钱 < -5万、或快乐 < 10 时高概率触发
- **出身专属转机**: 不同的出身触发不同的转机事件，更贴合背景
- **人生逆袭**: 连续绝境可能触发超级事件，全属性大幅提升
- **事件卡片**: 每年从 44 张事件卡中按优先级匹配，触发后不再重复（除非可重复）
- **连锁事件**: 某些选择会设置后续事件（如借钱 → 还钱），形成因果链
- **故事旗标**: 30+ 个 flag 追踪你的关键选择，影响结局生成
- **人物关系网**: 伴侣、朋友、父母，各有关系值（-100 ~ +100），事件选择会影响亲密程度

## 💾 存档说明

- 游戏**自动保存**到浏览器 localStorage
- 刷新页面后点击「继续游戏」即可继续
- 后端运行时，存档同步到服务器端 session

## 🔄 自动降级

- 前端优先调用后端 API
- 后端不可用时自动降级到本地只读模式（可查看存档但不能操作）
- 降级模式下快捷操作和「下一年」按钮均锁定

## 📁 项目结构

```
life_simulator/
├── core.py                # 游戏规则引擎（单源真相）
├── config.py              # 所有静态配置数据（事件卡、日常事件、出身、天赋等）
├── server.py              # Flask REST API（薄层，委托给 core.py）
├── test_core.py           # pytest 测试（16 个用例，覆盖关键路径）
├── game.py                # ⚠️ 已废弃：文本版原型（规则不同步）
├── gui.py                 # ⚠️ 已废弃：Tkinter GUI 原型（规则不同步）
├── web/
│   ├── index.html         # Vue 3 SPA 入口
│   ├── css/
│   │   └── style.css      # 暗色主题样式
│   └── js/
│       ├── game-vue.js    # Vue 应用入口（组装状态/API/UI 模块）
│       ├── game-state.js  # 状态管理 + 存档 + 工具函数
│       ├── game-api.js    # API 调用封装 + 后端连通性检测
│       └── game-ui.js     # 事件卡渲染 + Modal + 服务器响应处理
├── openspec/
│   ├── specs/             # 规范文档（事件卡片、人物关系、故事旗标、日常事件）
│   └── changes/           # 变更历史（叙事引擎、死代码清理等）
├── archive/               # 旧版前端文件（game.js、index-vue.html）
├── CLAUDE.md              # AI 编程助手引导文件
├── FEATURES.md            # 详细功能文档
├── new.md                 # 未来功能设计草案
└── README.md
```

## 🔧 技术栈

- **后端**: Python 3 + Flask + Flask-CORS
- **前端**: Vue 3（CDN 加载，ES module）+ 原生 CSS（暗色主题）
- **测试**: pytest
- **规范驱动开发**: OpenSpec（spec-driven schema）
