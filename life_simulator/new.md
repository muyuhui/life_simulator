# 《熬过去 - 人生模拟器》新增功能设计文档
## 文档说明
本文档基于游戏核心设计理念「熬过去就会好」（体验人生韧性、低死亡概率、绝境有转机），梳理新增功能模块及细节规则，用于游戏迭代升级，所有新增功能均围绕「强化核心特色、提升沉浸感、增加趣味性」设计。

## 一、核心特色强化：绝境转机差异化
### 1.1 转机类型绑定人生背景
#### 设计目标
让转机事件更贴合玩家初始出身，增强剧情真实感和代入感，避免转机体验同质化。
#### 功能规则
| 出身类型 | 专属转机事件（触发概率：转机时80%替换通用事件） | 数值效果 |
|----------|------------------------------------------------|----------|
| 农村出身 | 1. 同乡介绍高薪零工：金钱+1~3万，事业+5~10<br>2. 老家征地补偿：金钱+5~8万<br>3. 亲戚帮扶创业启动金：金钱+3~5万，事业+10~15 | 基础改善幅度 +10% |
| 小镇青年 | 1. 老同学推荐县城稳定工作：事业+15~20，金钱+2~4万<br>2. 家乡特产带货机会：金钱+2~5万，快乐+5~10<br>3. 父母托人介绍本地对象：解锁相亲成功保底，快乐+10~15 | 基础改善幅度 +5% |
| 城市中产 | 1. 前同事推荐高薪跳槽：金钱+5~10万，事业+20~25<br>2. 冷门理财产品盈利：金钱+8~12万<br>3. 技能证书补贴：事业+15~20，金钱+1~2万 | 基础改善幅度 +8% |
| 富二代 | 1. 家族人脉提供创业资源：事业+30~40，金钱+10~20万<br>2. 海外投资小额收益：金钱+15~25万<br>3. 长辈赠予资产：金钱+20~30万 | 基础改善幅度 +15% |
#### 附加规则
- 触发专属转机后，解锁对应「人生标签」（如「乡土帮扶」「人脉红利」），标签可叠加，后续同类事件收益+5%；
- 健康<20触发转机时，额外解锁「惜命」buff：后续健康值下降速度再-20%（可与「健康体质」天赋叠加）。

### 1.2 连环转机彩蛋
#### 设计目标
奖励持续处于绝境但坚持下来的玩家，强化「熬过去就会逆袭」的核心体验。
#### 功能规则
1. 触发条件：连续2次及以上触发绝境转机（无间隔正常年份）；
2. 彩蛋概率：满足条件后，下一次转机有10%概率触发「人生逆袭」超级事件；
3. 超级事件效果：
   - 数值提升：基础改善幅度×2（如大改善从+40~60%变为+80~120%）；
   - 解锁成就：「否极泰来」（新增成就）；
   - 永久buff：「逆袭者」（后续所有事件负面效果-10%）。

### 1.3 转机的代价与温情
#### 设计目标
让转机更贴近真实人生，既有收获也有取舍，同时增加情绪价值。
#### 功能规则
| 转机类型 | 触发条件 | 收益效果 | 代价/附加效果 |
|----------|----------|----------|---------------|
| 借钱渡难关 | 金钱<-5万触发转机（30%概率） | 金钱+5万 | 后续10年每年扣除5%收入用于还债 |
| 家人兜底 | 健康<20 或 快乐<10 触发转机（25%概率） | 健康/快乐+20~30 | 未来2年事业/金钱增长速度-10% |
| 陌生人善意 | 任意绝境触发转机（15%概率） | 随机属性+10~15 | 无代价，解锁短剧情文本（如「捡到钱包归还获感谢金」） |
| 老友相助 | 快乐<10 触发转机（20%概率） | 快乐+25~35 | 解锁「友情羁绊」buff（后续社交事件收益+10%） |

## 二、玩法拓展：人生分支与选择
### 2.1 关键年龄节点重大选择
#### 设计目标
增加人生轨迹的不可逆性，强化「选择决定人生」的体验，避免事件碎片化。
#### 功能规则
在指定年龄强制触发分支选择，选择后影响后续事件池和属性成长：
| 关键年龄 | 可选分支 | 选择效果 | 后续影响 |
|----------|----------|----------|----------|
| 18岁（高考后） | 1. 复读冲名校 | 快乐-20，学历（本科）成功率+40% | 后续考研/考博成功率+10%，公务员/教师类职业解锁概率+20% |
|          | 2. 直接打工 | 金钱+1万，学历锁死高中 | 解锁工人/司机/服务员等蓝领职业高阶成长（成长率+1%），无法解锁硕士/博士学历 |
|          | 3. Gap Year旅行 | 快乐+30，金钱-5千 | 解锁「见多识广」buff（社交事件收益+15%），旅行类事件概率+30% |
| 25岁（职业定型前） | 1. 深耕现有职业 | 事业+15~20，失业风险-10% | 职业成长率+2%，每年有5%概率触发升职事件 |
|          | 2. 跨行业转行 | 事业-10~15，快乐-5~10 | 解锁新职业池（如程序员转网红），高风险高回报事件概率+15% |
|          | 3. 创业试水 | 金钱-5~8万，风险+20% | 解锁「创业新手」标签，后续创业者职业成功率+10% |
| 35岁（中年危机） | 1. 求稳为主 | 放弃随机创业机会 | 失业风险-15%，金钱/事业增长速度-5% |
|          | 2. 孤注一掷 | 创业风险+20% | 创业成功后收益×1.5，失败则金钱-10~15万 |
|          | 3. 培养新人 | 事业-5~10 | 解锁「导师」buff（后续职业成长率+3%），每年有概率获得额外收入 |
| 50岁（人生下半场） | 1. 提前退休 | 金钱增长速度-50% | 快乐值衰减-50%，健康下降速度-30% |
|          | 2. 继续打拼 | 快乐-10~15 | 事业成长率+4%，有概率触发「行业元老」事件（金钱+10~20万） |
|          | 3. 发展兴趣 | 事业-5~10 | 快乐+20~30，解锁作家/网红等兴趣类职业高阶玩法 |

### 2.2 性格/天赋成长变异
#### 设计目标
打破初始天赋/性格的固定性，让人生成长更具动态性。
#### 功能规则
1. 性格变异：
   - 触发条件：连续3次同类极端事件（如冒险型玩家连续3次创业失败、稳健型玩家连续5次错过高收益事件）；
   - 变异效果：50%概率切换为互补性格（如冒险型→稳健型），或解锁混合性格（如「稳健但敢拼」：风险事件-10% + 高回报事件+15%）；
2. 天赋进阶：
   - 触发条件：对应天赋事件成功触发10次（如学习天赋玩家10次考试/学习成功）；
   - 进阶效果：解锁天赋进阶版，效果强化且新增附加收益：
     | 初始天赋 | 进阶天赋名称 | 进阶效果 |
     |----------|--------------|----------|
     | 学习天赋 | 学霸导师     | 考试成功率+30% + 每年可带新人获得5000~1万金钱 |
     | 社交达人 | 人脉之王     | 社交事件收益+20% + 每月触发一次免费相亲/聚会事件 |
     | 财运亨通 | 投资嗅觉     | 金钱事件收益+30% + 股票收益波动+10%（上限不超50%） |
     | 健康体质 | 养生达人     | 健康下降-50% + 医院治疗效果+20% |

## 三、沉浸感提升：生活化细节
### 3.1 小确幸/小确丧日常事件
#### 设计目标
增加「过日子」的体感，补充碎片化情绪反馈，不影响核心数值平衡。
#### 功能规则
1. 触发频率：每月随机触发1次（替代部分无意义的空白月份）；
2. 事件类型（无决策成本，纯数值小幅波动）：
   | 事件分类 | 具体事件 | 数值效果 |
   |----------|----------|----------|
   | 小确幸   | 买到喜欢的奶茶 | 快乐+2 |
   |          | 加班后老板给加班费 | 金钱+500 |
   |          | 宠物撒娇 | 快乐+3 |
   |          | 走路捡到100元 | 金钱+100，快乐+1 |
   |          | 同事分享零食 | 快乐+2 |
   | 小确丧   | 上班迟到扣钱 | 金钱-200 |
   |          | 手机没电错过消息 | 快乐-2 |
   |          | 健身拉伤 | 健康-5 |
   |          | 外卖撒漏 | 快乐-3 |
   |          | 下雨没带伞 | 健康-2，快乐-1 |

### 3.2 人生资产精细化
#### 设计目标
扩充「买房」单一资产维度，增加资产的动态性和取舍感。
#### 功能规则
1. 房产分级（可升级/变卖）：
   | 房产类型 | 购买成本 | 快乐加成 | 附加效果 | 年升值/贬值幅度 | 变卖收益 |
   |----------|----------|----------|----------|----------------|----------|
   | 出租屋   | 0（免费） | -5       | 无       | 0              | 0        |
   | 小户型   | 10万     | +10      | 每年可出租获得5000~8000金钱 | ±3%      | 成本×80%~110% |
   | 大户型   | 50万     | +20      | 每年可出租获得2~3万金钱 | ±5%      | 成本×80%~120% |
   | 别墅     | 200万    | +40      | 每年可出租获得8~10万金钱，但需5万保养费 | ±8%      | 成本×80%~130% |
   - 绝境变卖规则：健康<20/金钱<-8万时，可选择变卖房产，变卖收益×1.2（紧急溢价），但快乐值-20~50（根据房产等级）；
2. 其他资产：
   | 资产类型 | 购买成本 | 效果 | 附加成本/风险 |
   |----------|----------|------|---------------|
   | 代步车   | 5万      | 通勤类事件收益+5% | 每年保养费2000 |
   | 豪车     | 50万     | 通勤类事件收益+10% + 社交事件快乐+5 | 每年保养费5万 |
   | 收藏品   | 1~10万   | 随机升值（5%概率翻倍，10%概率贬值50%） | 无 |
   | 奢侈品   | 5~20万   | 快乐+5~10 | 每年保养费1~3千 |

### 3.3 人际关系深度化
#### 设计目标
将「结婚/儿女成群」从单纯成就升级为动态互动系统，增加情感羁绊。
#### 功能规则
1. 伴侣系统：
   - 伴侣获取：相亲成功后解锁，随机生成伴侣属性；
   - 伴侣类型及buff：
     | 伴侣类型 | 核心buff | 互动事件 |
     |----------|----------|----------|
     | 节俭型   | 每年省10%开支 | 「一起省钱」：金钱+5000，快乐+5 |
     | 乐观型   | 快乐衰减-10% | 「情绪疏导」：快乐+15，无金钱消耗 |
     | 事业型   | 职业成长率+2% | 「职场建议」：事业+10，风险+5% |
     | 顾家型   | 健康下降-10% | 「日常照顾」：健康+5~10，快乐+5 |
   - 伴侣互动：每年可选1次互动，触发对应效果（吵架冷战为随机事件，无主动选择）；
2. 子女系统：
   - 子女成长：0~18岁每年触发「教育选择」事件；
     | 教育选择 | 消耗 | 效果 |
     |----------|------|------|
     | 报兴趣班 | 金钱-5千 | 子女未来天赋+5% |
     | 散养     | 无   | 快乐+5，子女性格随机 |
     | 严厉管教 | 快乐-5 | 子女未来学历成功率+10% |
   - 子女回馈/帮扶（18岁后）：
     | 子女状态 | 触发概率 | 效果 |
     |----------|----------|------|
     | 考上名校 | 20%      | 快乐+30，事业+10 |
     | 创业成功 | 10%      | 金钱+10万 |
     | 欠债     | 5%       | 金钱-5万，快乐-10 |
     | 日常孝顺 | 30%      | 金钱+1~2万，快乐+5 |

## 四、趣味性拓展：彩蛋与隐藏玩法
### 4.1 人生bug彩蛋
#### 设计目标
奖励极端数值探索，增加游戏趣味性和话题性。
#### 功能规则
| 触发条件 | 隐藏事件 | 效果 | 解锁成就 |
|----------|----------|------|----------|
| 金钱>1000万 + 快乐<10 | 花钱买快乐 | 花100万举办慈善晚宴，快乐+50 | 千金难买我开心 |
| 健康100 + 职业=程序员 | 卷王但健康 | 事业+20，未来5年无加班健康损耗 | 不猝死的程序员 |
| 连续10年选佛系操作 | 隐居结局 | 提前退休，快乐满值，金钱每年-5% | 人间佛系玩家 |
| 30岁前触发5次转机 | 人生小强 | 所有属性衰减-10%，转机概率+5% | 打不倒的小强 |

### 4.2 反向趣味成就
#### 设计目标
补充正向成就之外的趣味维度，增加自嘲式快乐，不影响核心体验。
#### 功能规则
| 成就名称 | 解锁条件 | 图标 | 成就效果（无数值影响，纯标签） |
|----------|----------|------|--------------------------------|
| 月光族   | 连续5年年底金钱<1000 | 💸 | 解锁「今朝有酒今朝醉」标签 |
| 职场摸鱼 | 连续3年职业成长率为0 | 🐟 | 解锁「带薪摸鱼大师」标签 |
| 恋爱绝缘体 | 50岁未触发相亲成功事件 | 💔 | 解锁「单身贵族」标签 |
| 间歇性踌躇满志 | 1年内既选健身又选躺平≥3次 | 🤸 | 解锁「矛盾体」标签 |
| 创业钉子户 | 连续3次创业失败仍选择创业 | 🚀 | 解锁「越挫越勇」标签 |

### 4.3 节日限定事件
#### 设计目标
增加时间维度的沉浸感，让人生体验更贴近现实。
#### 功能规则
1. 触发节点：春节、中秋、生日、情人节（每年固定触发）；
2. 事件内容（随人生状态动态变化）：
   | 节日 | 人生状态 | 可选事件 | 效果 |
   |------|----------|----------|------|
   | 春节 | 单身 | 1. 回老家拜年：快乐+10，金钱-5千<br>2. 春节加班：金钱+2万，快乐-5 | 无 |
   |      | 已婚 | 1. 全家团圆：快乐+20，金钱-1万<br>2. 走亲访友：快乐+15，金钱-8千 | 无 |
   | 生日 | <30岁 | 1. 朋友庆祝：快乐+15，金钱-1千<br>2. 独自度过：快乐+5 | 无 |
   |      | ≥50岁 | 1. 子女祝寿：快乐+30，金钱+2万<br>2. 回忆人生：快乐+10，解锁人生复盘短报告 | 无 |
   | 情人节 | 单身 | 吃狗粮：快乐-3（不可选） | 触发「相亲加速」：下月相亲成功率+10% |
   |        | 已婚 | 烛光晚餐：快乐+10，金钱-2千 | 伴侣buff效果+5%（持续1年） |

## 五、体验优化：辅助功能
### 5.1 人生复盘功能
#### 设计目标
让玩家感知人生轨迹，强化「成长与韧性」的核心体验。
#### 功能规则
1. 触发节点：30/50/70/100岁自动触发；
2. 复盘内容：
   - 核心数据：总赚金额、触发转机次数、换工作次数、解锁成就数；
   - 趣味标签：「最惨的一年（如28岁：健康15，金钱-8万）」「最幸运的时刻（如35岁彩票中5万）」「人生关键词（坚韧/折腾/佛系）」；
   - 对比数据：与「平均玩家人生」对比（如「你的快乐值比80%玩家高」「你的转机次数是平均水平的1.5倍」）；
3. 输出形式：可视化报告（文字+简易图表），可保存至人生履历。

### 5.2 难度自定义
#### 设计目标
适配不同玩家的体验需求，扩大受众范围。
#### 功能规则
开局新增难度选择，核心规则调整如下：
| 难度等级 | 核心规则调整 | 适配玩家 |
|----------|--------------|----------|
| 普通模式 | 保持原有规则（转机90%、绝境阈值健康<20/金钱<-5万/快乐<10） | 核心目标玩家 |
| 硬核模式 | 1. 转机概率70%<br>2. 绝境阈值健康<10/金钱<-8万/快乐<5<br>3. 失业/生病概率+10%<br>4. 职业成长率-5% | 追求挑战的玩家 |
| 休闲模式 | 1. 转机概率100%<br>2. 快乐衰减-50%<br>3. 金钱事件收益+20%<br>4. 无强制负面事件 | 轻松体验的休闲玩家 |

### 5.3 随机稀有出身彩蛋
#### 设计目标
增加开局随机性和探索欲，补充特殊人生体验。
#### 功能规则
1. 触发概率：开局选择出身时，1%概率触发稀有出身（需手动确认是否选择）；
2. 稀有出身属性：
   | 稀有出身 | 初始属性 | 核心buff | 核心debuff |
   |----------|----------|----------|------------|
   | 流浪儿   | 金钱0，快乐10，健康50，事业0 | 触发转机后收益×2 | 初始3年无稳定职业，金钱获取难度+50% |
   | 星二代   | 金钱100万，快乐90，事业40 | 社交事件收益+30% | 每年快乐衰减+10%（事业压力） |

## 六、功能优先级建议
| 优先级 | 功能模块 | 开发建议 |
|--------|----------|----------|
| 高     | 绝境转机差异化、人生分支选择、小确幸/小确丧事件 | 核心体验强化，开发成本低，见效快 |
| 中     | 人生资产精细化、人际关系深度化、节日限定事件 | 提升沉浸感，需补充事件库，可分阶段开发 |

| 优化项 | 人生复盘、难度自定义 | 体验优化，建议在核心玩法上线后快速迭代 |
