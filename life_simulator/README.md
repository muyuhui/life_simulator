# 熬过去 - 人生模拟器

一款精心设计的Web人生模拟游戏，核心机制是**很难死掉**，每次绝境大概率会迎来转机！

## 🌟 特性

- **丰富的出身选择**: 小镇青年、城市中产、富二代、农村出身
- **多样天赋系统**: 学习天赋、社交达人、财运亨通、健康体质、天选之人
- **性格影响玩法**: 稳健型、冒险型、佛系型、卷王
- **三种难度模式**: 
  - 🌟 普通模式 - 转机率90%，适合新手
  - 🔥 硬核模式 - 转机率70%，更具挑战
  - ☀️ 休闲模式 - 转机率100%，轻松体验
- **转机系统**: 绝境时高概率触发转机，连续绝境触发「人生逆袭」！
- **人生事件**: 高考、考研、找工作、职业发展、相亲结婚、生子买房
- **成就系统**: 20+成就等你解锁
- **快速操作**: 医院、心理医生、彩票、相亲、买房、养宠物、旅行、股票

## 🚀 快速开始

### 方式一：直接运行Web版

```bash
# 使用Python内置HTTP服务器
cd life_simulator/web
python -m http.server 8080
```

然后浏览器打开 http://localhost:8080

### 方式二：运行完整版（后端API + 前端）

```bash
# 安装依赖
pip install flask flask-cors

# 启动后端服务
cd life_simulator
python server.py
```

然后浏览器打开 http://localhost:5000

## 🎮 游戏玩法

1. **创建角色**: 输入名字，选择出身、天赋、性格和难度
2. **度过每年**: 点击「下一年」推进时间
3. **做出选择**: 遇到事件时选择你的处理方式
4. **管理状态**: 使用快速操作恢复健康和快乐
5. **达成成就**: 活得更久、更有钱、更快乐！

### 核心机制

- **健康归零时**: 90%概率触发转机（绝境逢生），10%概率去世
- **金钱为负时**: 可能触发借钱、转机等事件
- **快乐过低时**: 触发转机的概率增加
- **连续绝境**: 可能触发「人生逆袭」超级事件！全属性大幅提升
- **天赋生效**: 学习天赋增加考试成功率，财运亨通增加收入等

## 💾 存档说明

- 游戏**自动保存**到浏览器 localStorage
- 刷新页面后点击「继续游戏」即可继续
- 关闭浏览器再打开也能继续上局
- 后端运行时存档会同步到服务器

## 🔄 自动降级

- 前端优先调用后端API
- 如果后端未运行，自动降级到本地模式
- 本地模式功能完整，只是没有服务器端存档
